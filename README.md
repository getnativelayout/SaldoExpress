## O que faz

- Consulta o saldo através de códigos USSD da operadora.
- Recarga rápida.
- Registo de vendas e relatório em PDF.
- Proteção do app com PIN.
- Avisa quando há uma versão nova.

## Instalação

1. Descarrega o ficheiro `SaldoExpress.apk` pelo botão acima.
2. Abre o ficheiro e permite a instalação de fontes desconhecidas, se o telemóvel pedir.
3. Se o Play Protect mostrar um aviso, toca em **Mais detalhes** e depois em **Instalar mesmo assim**.
4. Abre o app e segue o passo a passo para dar as permissões e ligar a acessibilidade.

Depois de instalado, o app avisa sozinho quando houver atualizações. Não precisas de voltar a esta página.

## Requisitos

- Android 5.0 (API 21) ou superior
- Ligação à internet

## Permissões

| Permissão | Para quê |
|---|---|
| Chamadas | Executar os códigos USSD |
| Estado do telefone | Identificar o SIM ativo |
| Internet | Verificar atualizações |
| Notificações | Avisar sobre operações |
| Acessibilidade | Ler os menus da operadora e responder automaticamente |

O SaldoExpress não faz chamadas de voz, não acede aos contactos e não partilha dados pessoais.
